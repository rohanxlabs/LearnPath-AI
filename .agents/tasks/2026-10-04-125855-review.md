# Roadmap screen visual redesign

The roadmap detail screen was transformed to match a target design: custom header with circular back button and "LEARNING PATH" eyebrow, larger typography for key elements (28px title, 26px progress percentage, 26px next step title), continuous vertical timeline with phase markers that show numbers instead of generic icons for active phases, and refined card styling (progress uses subtle background, next step uses periwinkle background with dark CTA button). All existing business logic, API calls, and navigation patterns were preserved.

**Watch for:** Locked lesson contrast may be insufficient (metadata and icon don't receive disabled-specific muting). Hardcoded rgba color in next step metadata bypasses theme tokens.

**Verdict**: APPROVED

## High-level view

The header was replaced with custom JSX that removes `ScreenHeader` entirely and implements the circular back button and eyebrow label inline. The progress card moved from a white `Card` component to a custom View with `colors.surfaceSubtle` background, achieving the light gray treatment shown in the design. The next step card swapped from `Card variant="selected"` to a custom View with `colors.primary` background and a dark-variant button, creating the strong periwinkle visual anchor. The timeline transformation is the most substantial change: phase content no longer wraps in bordered cards, phase markers now render phase numbers as text for active phases (instead of generic circle icons), and the rail positioning was refined to center properly under the markers. Locked lesson visual treatment shifted from applying opacity to the entire row to applying muted text color only, improving contrast while maintaining the "unavailable" signal. All lesson status icons changed from filled to outline variants.

## Custom header replaces ScreenHeader component

The original `ScreenHeader` component was removed. The new header is a custom flexbox: 48px circular back button with `surfaceSubtle` background next to "LEARNING PATH" eyebrow (12px bold uppercase, `primaryDark`, 1px letter spacing) and roadmap title (28px bold, `ink`, -0.2 letter spacing). Back button preserves `router.back()` and "Back to paths" accessibility label. The subtitle (roadmap goal) is no longer displayed.

## Next step card uses periwinkle background and dark CTA

The next step section moved from `Card variant="selected"` to a custom View with `backgroundColor: colors.primary` (strong periwinkle fill). Button changed to `variant="dark"`. The metadata text uses hardcoded `color: "rgba(14,14,18,0.65)"` instead of a theme token, bypassing the design system.

## Timeline rail positioning refined

The rail's `left` position changed from hardcoded `16` to computed `38 / 2 - 2 / 2` (evaluates to 18, centering the 2px rail under the 38px marker). The `top` position changed from `34` to `48`, starting the rail further below the first marker.

## Phase markers show numbers for active phases

Phase markers changed from showing generic icons (`circle-slice-8` for expanded, `circle-outline` for collapsed) to rendering the phase number (1, 2, 3...) as 14px bold text for active phases. Completed phases show a white check icon on green background, locked phases show a gray lock-outline icon on light gray background. Marker size increased from 34px to 38px. This gives each active phase a unique visual identity.

## Phase content no longer wrapped in bordered Card

The `phaseContent` View lost its border, background, and rounded corners. Only `flex: 1, marginBottom, padding` remain. Phase content now flows vertically without visual containers — the continuous timeline effect.

## Locked lesson visual treatment weakened

The original locked lesson style (`opacity: 0.75`) was applied to the entire row. This was removed, and only the lesson title receives `lockedText` (muted color). The metadata and icon render with their default colors (`textSecondary` for metadata, `textMuted` for icon), potentially reducing the visual distinction between locked and available lessons. The old opacity affected all elements uniformly; the new approach may leave locked lessons appearing too similar to available ones.

Recommended lessons gained a 1.5px blue border (`colors.primary`) in addition to their light background. Lesson icons changed from filled to outline variants (`check-circle-outline`, `play-circle-outline`). Recommended lesson icon color changed to `primaryDark` (darker than the `primary` used for available lessons).
