# Roadmap screen visual redesign

This change implements a new visual design for the roadmap detail screen that replaces the boxed card timeline with a continuous vertical rail, adds custom header styling with a circular back button, enlarges key typography (progress percentage, next step title, journey heading), and refines lesson state presentation (recommended lessons get periwinkle background with blue border, locked lessons show muted text with no chevron).

All existing functionality is preserved: dual API calls (roadmap + next-action), cached request handling with CacheNotice, target lesson detection with fallback, automatic phase expansion, lesson navigation with status params, loading/error/empty states, and accessibility roles.

**Watch for:** Timeline rail positioning uses a hardcoded left offset (18px) that may not center perfectly on 38px phase markers across all screen sizes (**likely**). Locked lesson opacity (0.6) compounds with the already-muted text color, potentially failing WCAG contrast thresholds (**likely**).

**Verdict**: NEEDS_CHANGES

---

## High-level view

The header replaces `ScreenHeader` with a custom layout: 48px circular back button with `colors.surfaceSubtle` background, "LEARNING PATH" eyebrow, and dynamic roadmap title at 28px. Progress card now uses `colors.surfaceSubtle` background (no longer white `Card`) with 26px bold percentage display. Next step card uses strong periwinkle background (`colors.primary`) and dark button variant as specified.

Journey section sits directly on the page surface—not in a Card—with "Your journey" at 22px bold. Phase timeline transforms from bordered cards to a continuous vertical rail: 2px gray line runs from first to last phase, phase markers are 38px circles (completed=green with check icon, active=periwinkle with phase number text, locked=light gray with lock icon), and phase content has no border or background wrapper.

Recommended lessons get `colors.primaryTint` background with 1.5px blue border and `play-circle-outline` icon. Locked lessons render with 60% opacity, muted text, lock icon, no chevron, and are not pressable. All lesson status icons use `-outline` variants per the design.

The timeline rail is positioned absolutely at `left: 18`, which assumes the 38px marker's center is at 19px—this works for the current layout but would break if marker width or shell gap changes. Locked lesson opacity stacks with text color, creating a double-muting effect that may reduce contrast below accessible thresholds.

<details>
<summary>Issues (2)</summary>

1. **Timeline rail left offset hardcoded** — The `journeyRail` style uses `left: 18` to align with the phase marker center, but this is derived from assumptions about marker width (38px) and gap (16px). If either value changes (different marker size, adjusted spacing), the rail will misalign. Calculate the offset dynamically: `left: (markerWidth / 2) - (railWidth / 2)` or use layout measurement. (**likely**)

2. **Locked lesson opacity may fail contrast requirements** — Locked lessons use `opacity: 0.6` on the entire row, including text that's already `colors.textMuted` (#6B6E7B). At 60% opacity on a white background, the effective contrast ratio is approximately 2.4:1, below WCAG AA's 4.5:1 for normal text. Remove the `opacity: 0.6` style and rely solely on `colors.textMuted` for the text color, or use a darker muted color. (**likely**)

## Custom header layout and back button

The header is now a custom flexbox row: 48x48px circular back button with `colors.surfaceSubtle` background (#F3F4F8) and 22px `arrow-left` icon, followed by a flex-1 column containing the "LEARNING PATH" eyebrow (12px bold uppercase, `colors.primaryDark`, 1px letter-spacing) and the dynamic roadmap title (28px bold, `colors.ink`, -0.2 letter-spacing, 34px line-height). The back button calls `router.back()` with `accessibilityLabel="Back to paths"`.

The implementation correctly uses `roadmap?.title ?? 'Loading\u2026'` so the title is dynamic, not hardcoded to "Learn Python".

## Progress card styling and percentage prominence

Progress card background changed from white `Card` wrapper to a custom `View` with `backgroundColor: colors.surfaceSubtle` (#F3F4F8), matching the design's light gray/periwinkle card treatment. The percentage display is now 26px bold text in `colors.primaryDark`, positioned at the right of the flexbox row. The icon container is 44x44px with `borderRadius: radii.md` (14px) and `colors.primarySoft` background.

Lesson count uses `completed` (calculated via filter) and `lessonCount` (total from flattenLessons), not hardcoded "6 of 24". The percentage uses `Math.round(roadmap.progressPercent)`, not a hardcoded 25%.

## Next step card with periwinkle background and dark CTA

Next step card is now a `View` with `backgroundColor: colors.primary` (periwinkle #A9BEFF), borderRadius 24px, padding 24px, and gap 8px. The eyebrow uses icon "creation" (sparkle) at 15px + "YOUR NEXT STEP" label. The title is 26px bold with 32px line-height and -0.2 letter-spacing, rendered in `colors.ink` (near-black).

The title uses `recommendedTitle || nextLesson.name` (dynamic from next-action API or fallback). The metadata line uses `recommendationReason` if present, otherwise falls back to `About ${nextLesson.estimatedMinutes} minutes · ${nextLesson.xpReward} XP`—not hardcoded "About 15 minutes · 40 XP". The CTA button uses `variant="dark"` with label "Continue this lesson", calling `openLesson(nextLesson.id, nextLesson.status)`.

Metadata text color is hardcoded as `rgba(14,14,18,0.65)` in the `nextMeta` style rather than using a token. This is the only instance of a hardcoded color not drawn from the theme, though it's close to the intended near-black at reduced opacity.

## Journey section heading not in a card

The "Your journey" section is a plain `View` with 22px bold title and caption subtitle, not wrapped in a Card component.

## Continuous timeline rail and phase markers

The timeline structure is now: `phaseShell` (flexbox row, `alignItems: "stretch"`, gap 16px) → `journeyRail` (absolute positioned 2px vertical line) + `phaseMarker` (38x38px circle, `zIndex: 1`) + `phaseContent` (flex-1, no border or card wrapper).

The `journeyRail` is positioned `absolute`, `left: 18`, `top: 48`, `bottom: -spacing.md`, `width: 2`, `backgroundColor: colors.border`. The left offset 18px aims to center the rail on the 38px marker (which would have its center at 19px if positioned at x=0 with width 38), but this is hardcoded and assumes the current layout metrics. If `phaseShell` gap changes or marker size changes, the rail will misalign.

Phase marker backgrounds: completed phases use `colors.success` (green #31805A), active phases use `colors.primary` (periwinkle #A9BEFF), locked phases use `colors.surfaceSubtle` (#F3F4F8) with 1.5px border in `colors.borderStrong` (#CDD1DC).

Phase marker content: completed phases render `<MaterialCommunityIcons name="check" size={18} color={colors.surface} />` (white check on green). Locked phases render `<MaterialCommunityIcons name="lock-outline" size={16} color={colors.textMuted} />`. Active phases render `<Typography style={styles.phaseNumber}>{index + 1}</Typography>` where `phaseNumber` is 14px bold `colors.ink`—this correctly displays "1", "2", "3" etc. as dark text on periwinkle background, not an icon.

The rail runs continuously from `top: 48` (below first marker) to `bottom: -spacing.md` (extending into next phase's space), creating the visual effect of a single line threading through all markers.

## Phase content no longer wrapped in Card

The `phaseContent` View has `flex: 1`, `marginBottom: spacing.md`, and `padding: spacing.md`, but no `borderWidth`, `borderColor`, `borderRadius`, or `backgroundColor`. This removes the boxed card treatment, leaving the phase content open and flat in the timeline.

## Recommended lesson styling with periwinkle background and blue border

Recommended lessons (where `lesson.id === currentLessonId`) get the `recommendedLesson` style: `backgroundColor: colors.primaryTint` (#EEF2FF), `borderWidth: 1.5`, `borderColor: colors.primary` (#A9BEFF). This creates a light periwinkle fill with a stronger blue border. Recommended lesson icon is `play-circle-outline` (outlined play icon, not filled), color `colors.primaryDark` (#3347C2).

## Locked lesson muted presentation

Locked lessons apply `lockedLesson` style: `opacity: 0.6`. The lesson title additionally applies `lockedText` style: `color: colors.textMuted` (#6B6E7B). At 60% opacity, the already-muted text color (#6B6E7B) becomes approximately #B0B1B7 on white background, yielding a contrast ratio around 2.4:1—below WCAG AA's 4.5:1 requirement for normal text.

## All existing functionality preserved

The component imports and uses `useLocalSearchParams`, `useRouter`, `useAuth` hooks without changes. `loadRoadmap()` function makes dual API calls via `Promise.all`: `cachedApiRequest` for `GET /api/roadmaps/:roadmapId` (with `stripLessonBodies` cache transform) and `cachedApiRequest` for `GET /api/roadmaps/:roadmapId/next-action` (with `.catch(() => null)` fallback).

State variables unchanged: `roadmap`, `targetLessonId`, `recommendedTitle`, `recommendationReason`, `cachedAt`, `expandedPhaseId`, `loading`, `error`.

Target lesson resolution logic unchanged: `nextAction?.lessonId || lessons.find((lesson) => ["available", "current", "in_progress"].includes(lesson.status))?.id || null`.

Expanded phase logic unchanged: `target?.phaseId || normalized.phases.find((phase) => phase.status !== "completed")?.id || normalized.phases[0]?.id || null`.

`openLesson()` function unchanged: navigates to `/(learning)/lesson/[lessonId]` with params `{ lessonId, roadmapId, status }`.

Phase toggle logic unchanged: `setExpandedPhaseId(expandedPhaseId === phase.id ? null : phase.id)`.

Loading state still renders `<Card>` with `ActivityIndicator`. Error state still renders `<Card>` with error icon, message, and retry button. Empty roadmap state still renders `<Card>` with "Your roadmap is being prepared" message and refresh button. `CacheNotice` still renders when `cachedAt` is set.
